The story of the hovercraft, which we named Cheburashka, began in September 2025. As part of the Introduction to Digital Manufacturing course, we were tasked with building a device with a non-standard design. That’s how I came up with the idea to build Cheburashka.

I didn’t want to copy anything from the internet, so I built it exactly as I had imagined it. By that point, I had already been working with drones and knew how to design models in Blender, so the development process got off to a quick start. Yes, Blender is the most user-friendly program for me, and it’s fairly easy to turn it into a decent CAD system using add-ons. But most importantly, Blender is very forgiving of mistakes, and that will save you more than once.

3D Printing

All 3D models were created in Blender. In total, three versions of Cheburashka were created, and perhaps this is not the end yet. Each time, some shortcomings would appear that had to be fixed in subsequent version

Here is the latest, highest‑quality, and most well‑thought‑out version. The Cheburashka body is waterproof if the engineering hole for the wires of the main cushion motor is sealed.

I printed all the parts on an Elegoo Neptune Plus 3D printer using PLA and PETG plastic.

Components

All that I list below is everything that is in my Cheburashka, this is not a recommendation for purchase and you can find better modules. After the list, I'll tell you what can be improved by modules.

  • Cheburashka's Brains - ESP 32
  • ESC for rotary engine - ESC 50A BLHeli (x2)
  • ESC for main engine - ESC 80A BLHeli
  • Rotary engines - BAT-Surpass B2808 1500KV (x2)
  • Main engine - Motor 3115 900kv Spinner Production
  • GPS and Compas Module - Matek GPS & Compass M8Q-5883
  • Accelerometer and Gyro Module - MPU 6050 (for Arduino)
  • Radio transmitter (Cheburashka control) - FRSKY R9mini-OTA
  • Radio resiever (Cheburashka control) - R9M Module
  • Radio resiever (Cheburashka control) - R9M Module
  • Video transmitter and camera - Foxeer camera
  • Superimposing data on analog video - MINI OSD
  • Propellers - 3.5" (5 lumps, x2) & 5" (3 lumps)

So, now a few of my recommendations. Of course, the ESP32 must be equipped with a Wi-Fi module. I also advise you to purchase a pin expander for the board.

I recommend buying rotary motors with a characteristic of the order of 2000-3000 KV. It will be more comfortable for 3.5" diameter propellers. The main engine should be of the order of 1500-2000 KV.

There are much more interesting radio transmitters, but I still advise you to look at the information about the ExpressLRS firmware. This firmware is also suitable for FrSky R9 Mini OTA. Such a connection can operate at a distance of up to ~15 km, which ensures high-quality signal reception and safe operation.

The battery can be from 4S to 6S. When using the 4S, you will be able to install a larger battery. I also advise you to buy shrink wrap and nylon wires of different thicknesses.

M3 bolts are used. Buy nylon ones about 1.5 cm long — you can always cut them to the desired length — as well as metal ones about 1 cm long. Don't forget about nuts and 4-mm-high insert bushings

Firmware

Now let's talk about how to flash esp32. I recommend doing this on a Unix system.

  • Install the Arduino IDE.
  • Please read the article. You need to download the firmware_vars.json on ESP32.
  • Open the esp32_firmware.ino file in IDE.
  • Install the necessary libraries:
    • Adafruit_MPU6050
    • Adafruit_Sensor
    • DHT
    • QMC5883LCompass
    • TinyGPS++
    • ESP32Servo
    • Sbus
    • ArduinoJson
    • LittleFS
  • Compile it. If the compilation is successful, connect the esp32 and download the firmware on ESP32.
